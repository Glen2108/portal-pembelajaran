Panduan Upload GitHub & Vercel Free

Aplikasi ini didesain 100% Client-Side Persistent yang menyimpan data pada `localStorage` browser dan mendukung pengautan tautan Google Drive tanpa biaya Firebase Storage.

  1. Simpan kode HTML ini sebagai `index.html`.
  2. Buat Repository baru di GitHub (misal: `informatika-sman4-manado`).
  3. Upload file `index.html` tersebut ke GitHub Repository Anda.
  4. Buka akun di Vercel.com, pilih "Import Project from GitHub".
  5. Klik Deploy. Website interaktif aktif secara gratis dan responsif di iOS/Android.
